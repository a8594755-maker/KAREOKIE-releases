# KAREOKIE

Free AI karaoke software and singing scores for **Windows 10 / 11 (64-bit)**.

**[Official website](https://kareokie.com/) · [Download for Windows](https://kareokie.com/download) · [All releases](https://github.com/a8594755-maker/KAREOKIE-releases/releases)**

- Import your own audio or video files and separate vocals from the backing track with AI.
- Follow synchronized lyrics, including furigana for Japanese songs.
- Practice singing with live microphone pitch scoring and a report after each song.
- Keep song processing and audio on your own PC. An NVIDIA GPU speeds up processing; a CPU version is available too.
- Use the app in English, Traditional Chinese or Japanese.

## Downloads and updates

Download the latest `KAREOKIE-Setup-x.y.z.exe` from the [official download page](https://kareokie.com/download) or this repository's **Releases**. The installed app checks for updates automatically and shows a notification when a new version is available.

See the website for [system requirements](https://kareokie.com/#requirements), [setup steps](https://kareokie.com/#getting-started), [frequently asked questions](https://kareokie.com/#faq) and the [changelog](https://kareokie.com/#changelog).
